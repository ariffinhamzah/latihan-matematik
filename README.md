# Latihan Matematik

## Pengenalan
Projek ini menyediakan lembaran kerja matematik yang ringkas untuk latihan penambahan mudah. Ia direka bentuk dalam format HTML supaya mudah dibuka dan dicetak. Sesuai untuk kanak-kanak yang baru belajar operasi tambah.

## Ciri-ciri
*   **Format A4:** Direka untuk dimuatkan dengan sempurna pada kertas saiz A4 apabila dicetak.
*   **Soalan Penambahan:** Mengandungi pelbagai soalan penambahan nombor satu digit.
*   **Ruang Jawapan:** Disediakan ruang untuk menulis jawapan.
*   **Mesra Kanak-kanak:** Susun atur yang jelas dan mudah dibaca.

## Cara Penggunaan
1.  Muat turun fail `index.html` atau klon repositori ini.
2.  Buka fail `index.html` menggunakan mana-mana pelayar web (contohnya: Chrome, Firefox, Edge).
3.  Tekan `Ctrl + P` (atau `Cmd + P` di Mac) untuk mencetak halaman tersebut.
4.  Pastikan tetapan cetakan disetkan kepada saiz kertas A4.
5.  Cetak dan sedia untuk digunakan!

## Sumbangan
Jika anda ingin menambah baik reka bentuk atau menambah jenis latihan lain, sila fork repositori ini dan hantar Pull Request.
